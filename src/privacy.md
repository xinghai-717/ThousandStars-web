# 隐私政策

**生效日期：** 2026年8月14日

**最后更新：** 2026年8月14日

欢迎使用“千星启动器”（以下简称“我们”或“本启动器”）。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全。本隐私政策旨在向您说明，当您使用我们的网站和启动器时，我们如何收集、使用、存储和保护您的信息。

请在使用我们的服务前，仔细阅读并理解本政策。**如果您不同意本政策的任何内容，请勿使用我们的服务。**

### 1. 我们收集的信息

我们收集信息的范围和方式取决于您使用的具体功能：

*   **您主动提供的信息**：当您通过我们的网站或启动器下载资源时，我们不会要求您注册或提供姓名、邮箱等个人身份信息。
*   **自动收集的信息**：与许多网站一样，我们的托管服务商（如 Cloudflare Pages）和链接指向的平台（如 GitHub）可能会自动记录一些标准信息，例如：
    *   **IP 地址**：用于识别您的大致地理位置和网络服务提供商。
    *   **浏览器类型和版本**、**操作系统**：用于优化您的访问体验。
    *   **访问时间**和**引荐来源**：用于统计和分析。
    *   **设备信息**：如果您下载并使用启动器，启动器本身可能不会主动收集信息，但其运行环境（如操作系统）可能会生成标准的日志文件。

> **请注意**：我们**不会**使用 Google Analytics 等第三方分析工具，也**不会**在启动器中嵌入任何用于收集用户行为数据的 SDK。

### 2. 我们如何使用信息

我们收集上述信息的目的仅限于：

*   **提供服务**：确保网站和下载链接的正常运行，以及资源的正常分发。
*   **优化体验**：分析访问数据，以改进网站内容和结构。
*   **安全保障**：监测和防止欺诈、滥用等安全威胁。

### 3. 信息的共享与披露

我们高度重视您的隐私，**不会出售、交易或出租您的任何个人信息**。

在以下特定且必要的情况下，我们可能会共享您的信息：

*   **与第三方服务提供商共享**：我们可能会与帮助我们运营网站、提供服务或进行分析的可信第三方服务商共享信息。例如，我们的网站托管于 Cloudflare Pages，下载服务依托于 GitHub Releases。这些服务商仅被允许为提供服务之目的使用您的信息，并需遵守相应的保密义务。
*   **法律法规要求**：在法律法规、法律程序、诉讼或政府主管部门强制性要求的情况下，我们可能会被要求披露您的个人信息。

### 4. 数据存储与安全

*   **存储地点**：网站托管服务商的数据中心（如 Cloudflare 的全球网络）以及文件存储服务商（如 GitHub）的服务器可能会涉及数据的跨境传输。使用我们的服务即表示您了解并同意这一点。
*   **安全措施**：我们采取符合行业标准的安全措施来保护您的信息，防止未经授权的访问、公开披露、使用、修改、损坏或丢失。然而，请您理解，没有任何一种互联网传输或电子存储方法是100%安全的。

### 5. 您的权利

根据适用法律，您对您的个人信息享有以下权利：

1.  **访问权**：获取我们持有的关于您的个人信息的副本。
2.  **更正权**：要求我们更新或更正您认为不准确的信息。
3.  **删除权**：要求我们删除您的个人信息（除非我们有法定理由需要保留）。
4.  **撤回同意**：对于我们基于您的同意而处理数据的行为，您有权随时撤回同意。

**如何行使您的权利？** 请通过下方“联系我们”中的方式向我们提出请求，我们会在核实您的身份后处理。

### 6. 第三方链接

我们的网站和启动器可能包含指向第三方网站或服务的链接（例如，指向 GitHub 或隐私政策页面的链接）。本隐私政策不适用于这些第三方网站，我们对这些网站的隐私实践不承担任何责任。我们建议您在访问这些第三方网站时，仔细阅读其各自的隐私政策。

### 7. 儿童隐私

我们的服务不面向 14 周岁以下的儿童。我们不会故意收集 14 岁以下儿童的个人信息。如果发现无意中收集了此类信息，我们将立即采取措施予以删除。

### 8. 本隐私政策的更新

我们可能会不时更新本隐私政策。我们会在本页面上发布任何更改，对于重大变更，我们可能会通过网站公告或电子邮件等方式提供更显著的通知。我们鼓励您定期查看本页面以了解最新信息。
